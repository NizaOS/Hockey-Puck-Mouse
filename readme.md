<h1>Hockey Puck Mouse (Bambu Kit Edition)</h1>
<hr>
<h2>Description</h2>
<p>The <strong>Hockey Puck Mouse</strong> is a custom engineered wireless mouse that combines the iconic circular aesthetic of late-90s computing with modern wireless precision. Built using the <strong>Bambu Lab Wireless Mouse Components Kit</strong>, this project features a fully custom 3D-printed enclosure designed for a compact, minimalist desktop setup.</p>
<h2>Why I Made This</h2>
<p>i made this becuase this design could be redeemed with modern lightweight materials and better internal hardware. it will be a functional piece of desk art and a testament to the versatility of the bambu laeb hardware ecosystem.</p>
